1. Matemática y Fenómenos Periódicos

Las funciones trigonométricas constituyen la herramienta matemática ideal para describir fenómenos periódicos. Un fenómeno es periódico cuando se repite a intervalos regulares de tiempo o espacio.

Ejemplos reales: El latido cardiaco, el movimiento planetario, las ondas sonoras, la vibración de estructuras y la corriente eléctrica alterna.

Para modelar estos fenómenos, se requiere que los dominios de estas funciones abarquen números reales (ℝ).

2. Funciones Periódicas

Definición formal: Sean T > 0 y f una función real definida en ℝ. Se dice que f es periódica de periodo 2T si y solo si cumple:

f(x + 2T) = f(x),   ∀ x ∈ ℝ

3. Funciones Seno y Coseno

Función Seno: y = sen(x)

  • Dominio: ℝ
  • Recorrido: [-1, 1]
  • Periodo: 2π
  • Paridad: Impar (sen(-x) = -sen(x))
  • Cortes eje X: x = nπ (n ∈ ℤ)
  • Amplitud: 1

Función Coseno: y = cos(x)

  • Dominio: ℝ
  • Recorrido: [-1, 1]
  • Periodo: 2π
  • Paridad: Par (cos(-x) = cos(x))
  • Cortes eje X: x = π/2 + nπ (n ∈ ℤ)
  • Amplitud: 1

4. Transformaciones de Gráficas

Para y = A·sen(Bx + C) + D o y = A·cos(Bx + C) + D:

  • Amplitud (|A|): Distancia desde el eje central al punto máximo/mínimo.
  • Periodo (T): Calculado mediante T = 2π / B.
  • Frecuencia: Determinada por B.
  • Desplazamiento Vertical (D): Sube si D > 0, baja si D < 0.
  • Desfase (-C/B): Desplazamiento horizontal.

Ejercicio Resuelto: f(x) = -3·sen(2x - π/3)

Amplitud = 3  |  Periodo = π  |  Desfase = π/6 (derecha)
