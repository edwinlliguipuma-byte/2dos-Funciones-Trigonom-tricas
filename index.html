1. Matemática y Fenómenos Periódicos

Las funciones trigonométricas constituyen la herramienta matemática más adecuada para describir fenómenos periódicos. Un fenómeno es periódico cuando se repite a intervalos regulares de tiempo o de espacio.

Ejemplos: El latido cardiaco, el movimiento de los planetas, la variación de presión que produce el sonido, el movimiento del péndulo, la vibración de un puente, la corriente eléctrica alterna y ciclos biológicos.

Para modelar estos fenómenos, se requiere que los dominios de estas funciones sean conjuntos de números reales (ℝ).

2. Funciones Periódicas

Definición: Sean T > 0 y f una función real definida en ℝ. Se dice que f es periódica de periodo 2T si y solo si verifica:

f(x + 2T) = f(x),   para todo x ∈ ℝ

3. Funciones Seno y Coseno

Función Seno: y = sen(x)

  • Dominio: ℝ
  • Recorrido: [-1, 1]
  • Periodo: 2π
  • Paridad: Impar (sen(-x) = -sen(x))
  • Cortes eje X: x = nπ
  • Amplitud: 1

Función Coseno: y = cos(x)

  • Dominio: ℝ
  • Recorrido: [-1, 1]
  • Periodo: 2π
  • Paridad: Par (cos(-x) = cos(x))
  • Cortes eje X: x = π/2 + nπ
  • Amplitud: 1

4. Transformaciones de Gráficas

Para y = A·sen(Bx + C) + D o y = A·cos(Bx + C) + D:

  • Amplitud (|A|): Promedio entre max y min. Si |A|>1 dilata; si |A|<1 contrae.
  • Periodo (T): T = 2π / B.
  • Frecuencia: Determinada por B.
  • Desplazamiento Vertical (D): Sube si D>0, baja si D<0.
  • Desfase (-C/B): Desplazamiento horizontal.

Ejercicio Resuelto: f(x) = -3·sen(2x - π/3)

Amplitud = 3 | Periodo = π | Desfase = π/6 (derecha)
